# Projet R : Visualisation des notes du second groupe

## Description
Ce projet est un exercice en R pour pratiquer :  
- La création de vecteurs et data frames  
- Les calculs statistiques : moyenne, somme, max, min  
- La visualisation des données avec ggplot2 : barplot et scatter plot  
- L’ajout de la moyenne sur le graphique et personnalisation avec couleurs, titres et thèmes

---

## Contenu du projet
- `notes2_ggplot.R` : script R contenant le code pour les calculs et les graphiques  
- `notes2_barplot.png` : image du barplot  
- `notes2_scatter.png` : image du scatter plot  
- `README.md` : ce fichier d’explication

---

## Instructions pour exécuter le code
1. Cloner ou télécharger le repository  
2. Ouvrir `notes2_ggplot.R` dans RStudio  
3. Exécuter le code ligne par ligne ou tout le script  
4. Observer les résultats dans la console et les graphiques dans l’onglet **Plots**  

---

## Calculs statistiques pour le vecteur `notes2`
- Moyenne : 12.83  
- Somme : 77  
- Note maximale : 17  
- Note minimale : 8  

---

## Graphiques
- **Barplot** : chaque barre représente une note, la couleur varie selon la note, et la ligne rouge montre la moyenne  
- **Scatter plot** : chaque point représente une note, la ligne rouge indique la moyenne
